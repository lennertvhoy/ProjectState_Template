# Incidents

Use this directory for observed bad behavior, regressions, and quality gate
failures that require durable follow-up.

Incident notes are not blame reports. They are product-truth records that connect
the observed event to:

- severity and execution mode;
- a failure scan;
- a regression fixture or equivalent durable proof;
- the missing invariant;
- runtime/live proof when applicable;
- post-deploy watch when applicable;
- residual risk at closure.

Use `INCIDENT_RESPONSE.md` for the canonical workflow and incident note template.
