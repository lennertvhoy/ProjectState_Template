---
name: "close-slice"
gate_level: 2
evidence_max: 8
cheapest_proof: "Authoritative local gate plus policy-governed exact-head remote and post-merge verification"
escalate_when: "Release or template migration requires level 3 with CI proof"
description: "Execute full slice closure through policy-governed merge, main CI, cleanup, and external handoff"
when_to_use:
  - "Closing an implementation slice"
  - "User-facing or operator-facing changes ready for acceptance"
  - "Before marking any work as closure-grade"
required_inputs:
  - "Slice ID or scope description"
  - "Current branch with changes"
  - "Evidence collected during implementation"
  - "Human-confirmed delivery policy"
step_by_step:
  - name: "Run authoritative local quality gate"
    command: "python3 scripts/projectstate_quality_gate.py --gate-level 2"
    expected: "Exit 0 after all applicable suites and local checks run"
    failure: "Fix every aggregated failure and re-run the same command"
    notes: "Independent agents use full clones; trusted-local worktrees require the declared safety opt-in."
  - name: "Commit implementation proof"
    action: "Commit only classified slice work, then record that commit as the evidence proof head"
    verify: "Clean worktree and tracked evidence; no final-head or future-merge self-reference is fabricated"
  - name: "Finalize stable state and tracked evidence"
    action: "Mark canonical state validated_local_remote_pending, keep the backlog item active, append the local boundary to WORKLOG, and hash the strict tracked evidence pack"
    verify: "Tracked proof binds the proof tree, claims, tests, source hashes, final PR head, and evidence folder; it does not predict a provider-created merge SHA"
  - name: "Push and open or update the pull request"
    action: "Push normally; make the PR body name the proof head, exact final PR head, and evidence folder; keep the PR draft until local proof is complete"
    verify: "PR head equals local and remote branch HEAD"
  - name: "Finish according to confirmed policy"
    action: "For agent_after_green, run the authoritative finish command. For human_merge, stop after exact-head remote closure and report the deliberate manual boundary. Never change the confirmed mode silently."
    command: "python3 scripts/projectstate_finish_slice.py --root . --pr-number <pr> --expected-pr-head <sha> --delivery-policy PROJECT_STATE.yaml --evidence-folder <folder> --merge-method squash --handoff-output <external.json>"
    expected: "For agent_after_green, exit 0 only after PR readiness, exact-head CI/review/merge checks, remote finalizer, expected-head merge, direct main CI, post-merge equivalence, external handoff, remote-branch deletion, and a release receipt proving the original isolation path is absent"
    failure: "Retain recoverable branch and isolation state; report the last observed state-machine transition and resume idempotently after repair. If the clone is deliberately cancelled, explicit abandon may quarantine it only when clean and must not claim post-merge validation."
    notes: "The external sidecar owns merge commit, default-branch head, main CI, and cleanup truth. Clean full clones move to the recoverable quarantine outside the project parent; clean opted-in worktrees are removed without force. Dirty or unproven isolation is retained and HANDOFF_COMPLETE is refused."
expected_outputs:
  - "Authoritative local quality gate passes"
  - "Exact-head branch-head and merge-candidate CI pass"
  - "Remote closure finalizer passes immediately before merge"
  - "Direct default-branch CI and post-merge verifier pass"
  - "State and strict evidence pack are tracked and aligned"
  - "External remote-first handoff, verified cleanup, and clean isolation"
failure_cases:
  - name: "Local gate fails"
    detection: "projectstate_quality_gate.py exits non-zero"
    recovery: "Fix all reported failures and rerun the authoritative command"
    evidence: "Quality-gate output"
  - name: "Remote closure not verified"
    detection: "projectstate_remote_closure_finalizer.py exits non-zero"
    recovery: "Align exact heads, PR body, evidence, CI, review threads, and merge state without merging"
    evidence: "Remote finalizer output"
  - name: "Merge or main verification fails"
    detection: "projectstate_finish_slice.py exits non-zero before HANDOFF_COMPLETE"
    recovery: "Preserve recoverable state and rerun; an existing merge is verified idempotently rather than repeated"
    evidence: "External partial handoff and provider observations"
evidence_required:
  - "Authoritative quality-gate output"
  - "Strict tracked evidence bundle"
  - "Runtime/browser proof only when the change type requires it"
  - "Remote finalizer output"
  - "External post-merge handoff with merge/default-head/CI identities"
exit_criteria:
  - "For agent_after_green, local gate, exact-head remote finalizer, direct main CI, and post-merge verifier exit 0"
  - "State files pass check_state_docs.py"
  - "Remote branch deletion and isolation release occur only after verified closure"
  - "The closed-world release receipt proves the exact original isolation path is absent"
  - "Acceptance is recorded only when a human actually accepted the result"
