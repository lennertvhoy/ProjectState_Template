---
name: "improve"
gate_level: 2
evidence_max: 1
cheapest_proof: "Per-slice authoritative level-2 quality-gate pass plus a final improvement ledger separating implemented, validated, unvalidated, and blocked work"
escalate_when: "Work would leave the autonomy ladder, any authoritative gate cannot be repaired, or stop condition B (genuine blocker) is reached"
description: "Autonomous multi-slice improvement loop: assess, prioritize, implement vertically, validate, falsify, close, repeat"
when_to_use:
  - "A human or the CTO lane invokes /projectstate-improve to delegate maintenance-class slice selection for one bounded run"
  - "A repository needs defect repair, measured improvement, validation gaps closed, documentation rot fixed, implied capabilities completed, or developer-experience friction removed across several slices"
  - "Resuming an interrupted improve run recorded in the latest WORKLOG entry"
required_inputs:
  - "Repository path with declared ProjectState mode and observed execution_mode"
  - "Eligible change classes for this run (use the freeze accepted_change_classes when a quality freeze is active)"
step_by_step:
  - name: "Preflight and authority"
    command: "python3 scripts/projectstate_doctor.py && python3 scripts/projectstate_git_safety_check.py --mode normal_branch"
    action: "Confirm clean classified start, read execution_mode and any freeze scope, and record that this invocation delegates maintenance-class selection for the run"
    expected: "Mutation permitted on a private slice branch; eligibility boundary recorded in run notes"
    failure: "Dirty or ambiguous start: classify and preserve with the worktree guard first; never reset or discard"
  - name: "Source-of-truth pass"
    action: "Map canonical versus generated versus state versus derivative artifacts; reconcile documentation against implementation and tests"
    verify: "Corrections repair canonical sources; no second source of truth is created"
  - name: "Assessment sweep"
    action: "Sweep correctness defects, data-loss risk, security, reliability, broken journeys, missing validation, UX friction, documentation rot, dead code, developer experience, and strongly implied capabilities"
    verify: "Candidates ranked by value x confidence x reach x risk reduction divided by cost and complexity; each labeled FACT or ASSUMPTION; interim ranking stored in run notes"
  - name: "Select and contract one slice"
    action: "Take the highest-ranked eligible candidate; reuse or bind a stable BL ID; write the slice contract; run a failure scan for risky work"
    verify: "NEXT_ACTIONS carries exactly this one active item"
    failure: "Candidate needs ladder L3/L4 authority: park it and record the exact external action required instead of implementing"
  - name: "Implement vertically"
    action: "Deliver the complete vertical change: logic, interfaces, persistence, schema, migration, configuration, documentation, observability, and removal of superseded behavior"
    verify: "Diff avoids unrelated churn; subtraction preferred over addition when both solve the cause"
  - name: "Validate and falsify"
    command: "python3 scripts/projectstate_quality_gate.py --gate-level 2 --conformance --verbose"
    expected: "Gate passes, then the change survives attempted falsification: unhappy paths, interruption, repeated execution, stale or missing state, unavailable dependencies"
    failure: "Repair discovered weaknesses and rerun; descope honestly if not repairable"
  - name: "Close the slice"
    action: "Close through the close-slice skill: evidence pack, EVIDENCE_LOG entry, WORKLOG entry, queue and state updates"
    verify: "Claims match their evidence level; no transition crosses a truth boundary unproven"
  - name: "Loop or stop"
    action: "After major work re-inspect from the new state rather than rereading old findings; continue selecting ranked candidates while one remains safe, high-confidence, and high-value"
    verify: "Otherwise emit the final report via scripts/projectstate_handoff.py with Decisions, Changes, Validation split (implemented, validated, unvalidated, externally blocked), Remaining risks, Preserved work, External boundaries, and Exact next action"
failure_cases:
  - name: "Authoritative gate failure mid-loop"
    detection: "Any gate exits nonzero or hygiene checks fail"
    recovery: "Fix the underlying cause and rerun the same gate; never bypass, weaken, or declare partial work closure-grade"
    evidence: "Failing and passing gate output in the slice evidence pack"
  - name: "Genuine blocker"
    detection: "Progress requires credentials, hardware, protected data, external approval, an irreversible action, or a major product decision"
    recovery: "Complete everything possible first, record claim state blocked, and hand off naming the exact action that needs human authorization"
    evidence: "External-boundaries section of the final report"
  - name: "Scope creep"
    detection: "A candidate fails the real-defect, real-risk, implied-capability, substantial-friction, or material-simplification test"
    recovery: "Park it in BACKLOG with ranking rationale instead of implementing"
    evidence: "Run-notes ranking entries"
evidence_required:
  - "quality_gate_output.txt"
  - "run_notes.md"
exit_criteria:
  - "Every implemented improvement has passing level-2 gate evidence bound to its slice"
  - "The final report separates implemented, validated, unvalidated, and externally blocked work"
  - "The run stopped only at meaningful local closure or an honestly recorded genuine blocker"
